# Files Organizer

Простое консольное приложение на C# для автоматической сортировки файлов по папкам в зависимости от их расширения. Приложение помогает навести порядок в директории, распределяя файлы по категориям: изображения, текстовые документы, архивы, исполняемые файлы и прочее.

## Возможности

- Автоматическое определение типа файла по расширению.
- Создание папок для каждой категории файлов.
- Перемещение файлов в соответствующие папки.
- Цветное логирование процесса в консоли (успех, ошибка, предупреждение, информация).
- Циклическая работа: после сортировки одной папки можно указать путь к следующей.
- Обработка ошибок при доступе к файлам и директориям.

## Требования

- .NET Core 2.2 (или совместимая версия .NET).
- Операционная система: Windows, Linux или macOS.

## Установка

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/tryakindmitry217-hue/File-Organizer.git
   ```
2. Перейдите в директорию проекта:
   ```bash
   cd File-Organizer
   ```
3. Соберите проект:
   ```bash
   dotnet build
   ```

## Использование

Запустите приложение:

```bash
dotnet run
```

После запуска приложение запросит путь к папке, файлы в которой нужно отсортировать:

```
Enter path to sort out files:
```

Введите полный путь к директории. Приложение просканирует все файлы в указанной папке и переместит их в подпапки согласно расширению:

| Категория | Расширения |
|-----------|------------|
| Images | `.jpg`, `.jpeg`, `.png`, `.gif`, `.bmp`, `.ico` |
| Text Documents | `.txt`, `.doc`, `.docx`, `.exl`, `.pdf` |
| Archives | `.7zip`, `.zip`, `.rar` |
| Executable files | `.exe`, `.bat`, `.bin` |
| Other | все остальные расширения |

После завершения сортировки приложение спросит, хотите ли вы продолжить работу с другой папкой:

```
Continue sorting with another path? [y/n]:
```

Введите `y` для продолжения или `n` для выхода.

### Пример работы

```
Enter path to sort out files: C:\Users\User\Downloads
photo.jpg    OK.
document.pdf OK.
archive.zip  OK.
script.py    OK.
Continue sorting with another path? [y/n]: n
```
